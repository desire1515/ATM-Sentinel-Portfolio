02 / TESTING & LIMITATIONS

A prototype, in context.

✓

What this demonstrates

  • Analysis of a synthetic transaction dataset.
  • Precomputed anomaly outputs presented in a dashboard.
  • Review-oriented statistics and CSV export capabilities.
  • A separate MWK 100,000 withdrawal threshold rule.
!

What it does not claim

  • It is not connected to real banks or live ATM networks.
  • It does not prevent fraud in real time.
  • It is not a production-deployed banking service.
  • Performance on verified, labelled real banking data has not been established.
TESTING NOTE

Results are precomputed for this prototype. Synthetic demonstration counts should not be used to infer real-world fraud rates, model accuracy or financial risk.
